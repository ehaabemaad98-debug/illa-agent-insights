2 · Which day each agent unlocked the commission

…

Unlock day = the first day of the month the agent's progress card showed ≥70% of target (the app's own number). The 70% unlock event exists only in the Presell PWA today — both other apps already show commission progress, and card 4 asks for their unlock event; for their agents see the plan-derived table below. "Carried": the app emits the ≥70% flag once a day — an agent already above 70% when October closed only gets flagged on Nov 1, so the crossing is credited to October and shown as "crossed Oct — flag Nov 1" in the October column.
